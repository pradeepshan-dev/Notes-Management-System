# 📝 Notes Management System

A simple command-line **Notes Management System built with Python**.

This project allows users to add, view, delete all, and remove individual notes. The notes are stored permanently in a text file using Python file handling.

## ✨ Features

- ➕ Add a new note
- 👀 View all saved notes
- 🗑️ Delete all notes
- ❌ Remove a specific note
- 🔢 Select individual notes using numbers
- ⚠️ Handles invalid user input
- 💾 Stores notes in a `.txt` file
- 📂 Uses file handling for persistent storage

## 🛠️ Technologies Used

- Python
- File Handling
- Lists
- Functions
- Exception Handling
- Loops
- User Input
